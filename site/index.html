Open source, for Claude Code

Keep the lights on for the next agent.

Every coding session builds a map of what matters: what you asked for, what failed, what was decided. ccp compiles that session into a handoff, so the next agent picks up right where the last one stopped.

$npm install -g --install-links github:swethankreddy/context-compiler

  1. 01

    Your agent builds a map as it works.

    Requirements, corrections, decisions, the tests it ran. It all lives in the session.

  2. 02

    Then the session ends. The map goes dark.

    Compaction, a new chat, another agent. The code survives. Why it looks that way does not.

  3. 03

    Context Compiler keeps the lights on.

    It reads the session that ended and compiles the map into a handoff the next agent can act on.

    Four commands you will use.

    Run them in the project you were working on with Claude Code. Output is copied to your clipboard, ready to paste into the next agent.

    • $ ccp --handoffWrite a brief for a fresh agent that lacks the conversation.
    • $ ccp --recoverRebuild the task state after compaction or an interruption.
    • $ ccp "fix the auth issue"Compile a short instruction against the current session.
    • $ ccp contextSee everything it discovered. Nothing is sent anywhere.

    Private by construction.

    Your own Claude account

    Compilation runs through your signed-in claude CLI. ccp never reads your credentials.

    An isolated compile call

    A throwaway directory, no tools, no MCP servers, no hooks, no session history. It reads and answers, nothing else.

    Secrets redacted first

    API keys, tokens and private keys are removed before anything leaves your machine.

    Untrusted stays untrusted

    Text from files, tool output and pasted content is treated as data, never as instructions.
